# Mai Product

创建产品资料文件夹模板。新用户优先使用这个短入口。

默认使用简体中文和用户沟通：提问、讲解、错误提示、保存提示都用简体中文；模板字段保持当前 Markdown 模板格式。

## 输入

- 产品名或型号：必填，例如 `WT801`。
- 保存目录：可选。无法判断时询问用户。该目录下会创建 `<产品名>/` 文件夹。

## 执行

1. 确定产品名和保存目录。
2. 生成 `<产品名>/` 文件夹，并在其中写入 `product.md`。
3. 若文件夹或 `product.md` 已存在，不覆盖；询问用户是否换名或覆盖。
4. 写入下方模板。用户后续可以继续把规格、图片 brief、Listing 草稿、竞品资料等文件放进同一文件夹。
5. 告诉用户下一步可用：`使用 $mai --product <完整文件夹路径> 生成文案`。

若产品名或保存目录缺失，一次只问一个问题。保存目录问题使用数字选项：

```text
你想把产品资料保存到哪里？
1. 当前项目目录
2. ~/my-products/
3. 我提供一个文件夹路径
请回复数字即可。
```

## 文件夹结构

```text
{{PRODUCT_NAME}}/
└── product.md
```
