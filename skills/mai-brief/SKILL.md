# Mai Brief

创建文案需求模板。新用户优先使用这个短入口。

## 输入

- 需求名：必填，例如 `wt801-image2`。
- 保存目录：可选。无法判断时询问用户。
- `--type`：可选，默认 `image-copy`。

## 执行

1. 确定需求名、保存目录、文案类型。
2. 生成 `<需求名>.md`。
3. 若文件已存在，不覆盖；询问用户是否换名或覆盖。
4. 写入下方模板。
5. 告诉用户下一步可用：`使用 $mai --product <产品文件> --requirement <完整文件路径>`。

若需求名、保存目录或文案类型缺失，一次只问一个问题。文案类型问题使用数字选项：

```text
这个需求文件用于哪类文案？
1. 标题/副标题
2. 五点描述
3. 完整 Listing
4. A+ 内容
5. 图片/草图文案
6. 标语/广告语
请回复数字即可。
```
