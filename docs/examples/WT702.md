## 目标受众

- **园艺爱好者**（北美/欧洲）：关注根腐病/浇水过多问题，需要精准浇水
- **高频出行者**：经常旅行/出差，需要远程控制确保植物存活
- **智能家居爱好者**：追求 Home Assistant 等开放生态集成
- **环保意识用户**：关注节水，按需浇水减少浪费

## 关键卖点（按优先级排序）

1. **双区独立控制**：两个阀门独立调度（按时间或按水量），一台设备管理两个浇水区域
2. **无限电力**：太阳能 + 备用电池 + USB-C 三重供电，彻底消除户外电力焦虑
3. **精准浇水**：内置高精度 Flow Metering 流量计，按加仑/升精确浇水（防止过度浇水，节省水费）
4. **耐用性**：升级版黄铜进水口（Strip-Resistant，防剥落、防漏），IP65 防紫外线
5. **智能生态系统**：Wi-Fi 6 直连（无需昂贵 Hub），兼容 Alexa、Google Home、Smart Life、Home Assistant
